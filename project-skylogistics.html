Skylogistics Multi-Language Travel Website

A responsive travel-agency website built with Astro and Tailwind, localized across English, Bengali, and Malay, and deployed on Cloudflare Pages.

  • Astro
  • TailwindCSS
  • i18n
  • SEO
  • Cloudflare Pages

Problem

Skylogistics needed a modern web presence that could communicate services clearly to multilingual audiences and support direct customer inquiries.

My Role

I designed and built the site structure, reusable components, localization setup, metadata, and deployment flow.

Implementation

The site uses Astro components, Tailwind utility styling, hreflang support, OpenGraph metadata, JSON-LD, and a WhatsApp click-to-chat conversion path.

Outcome

The result is a fast, mobile-friendly website with strong SEO foundations and a content structure that can scale across languages.
