Transit map platform

Bus Tracking System

A Dockerized PHP application that visualizes Auckland route data on an interactive map and supports transit-oriented navigation workflows.

  • PHP
  • Docker
  • Leaflet
  • Transit Data

Problem

Transit users need clear route and location context, while developers need reliable data flows for updating map state.

My Role

I built the capstone-style project workflow for my Intelligent Transportation Systems module, covering the PHP app, map UI, and Dockerized setup.

Implementation

The app uses authenticated PHP pages, route selection, Leaflet map rendering, Auckland map tiles, route APIs, and journey planner navigation.

Outcome

The result is a practical transit dashboard that demonstrates real-time mapping concepts and full-stack transport-data integration.
